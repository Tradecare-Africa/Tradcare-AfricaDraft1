# TradeCare Africa — Integrated Agri-Services Ecosystem

Next.js (App Router) + TypeScript + Tailwind CSS v4 + lucide-react.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

- Content: `src/data/tradecareData.ts` (unchanged copy from the original site)
- Site config (contact, nav, downloads, images): `src/lib/site.ts`
- Theme tokens (TradeCare brand palette): `@theme` in `src/app/globals.css`
- The previous Vite version is preserved in `legacy-vite/` for reference.
